# Demon Slayer Pets · 카마도 탄지로 입지편

《귀멸의 칼날》 TV 애니메이션 1기를 바탕으로 만든 비공식 Windows 데스크톱 펫입니다. 탄지로, 네즈코, 젠이츠, 이노스케, 기유를 바탕화면에 불러올 수 있어요.

## 실행하기

[릴리스](https://github.com/baesaa0304/demon-slayer-pets/releases/tag/v1.0.0)의 **Assets**에서 DemonSlayerPets.exe를 내려받아 실행하세요. 탄지로가 화면 위에서 떨어져 등장합니다.

## 즐기는 방법

- 작업 표시줄 오른쪽 알림 영역에서 **Demon Slayer Pets** 아이콘을 우클릭해 캐릭터를 불러오거나 돌려보낼 수 있어요.
- 펫을 클릭하면 기술이 순서대로 나와요. 마우스로 끌어 올렸다 놓으면 낙하와 착지 연출을 볼 수 있어요.
- **기술 재생**에서 원하는 동작을 바로 재생할 수 있어요.
- **혈귀 전투 기술 선택**에서 사용할 기술을 고른 뒤 혈귀를 소환하세요. **혈귀 전체 소환**에서는 여러 펫이 혈귀를 나눠 맡아요.
- 기유는 물의 호흡 제4형으로 공격하고, 강적이 반격하면 제11형 **잔잔한 물결**로 막아요.
- 자동 기술 재생과 혈귀 자동 등장은 알림 영역 메뉴에서 켜거나 끌 수 있어요.
