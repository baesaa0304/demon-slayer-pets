# Demon Slayer Pets

탄지로, 네즈코, 젠이츠, 이노스케, 기유를 바탕화면에 불러와 각자의 기술로 혈귀와 싸우는 모습을 볼 수 있습니다.

## 캐릭터별 기술

| 캐릭터 | 혈귀전에서 사용할 수 있는 기술 |
| --- | --- |
| **탄지로** | **물의 호흡 제1~10형**, 응용기 **가로 물방아**와 **물방울 파문 찌르기·곡**, **히노카미 카구라 · 원무**. 물방아는 몸을 회전하며 베고, 원무는 검을 따라 불꽃을 그립니다. |
| **네즈코** | 공중에서 발을 뻗는 **도약 발차기**, 분홍 불꽃을 터뜨리는 혈귀술 **폭혈**. |
| **젠이츠** | 눈을 감고 옆으로 돌진하는 **번개의 호흡 제1형 · 벽력일섬**, 연속으로 여섯 번 돌진하는 **벽력일섬 6연**. |
| **이노스케** | 톱니 쌍검을 양옆으로 휘두르는 **짐승의 호흡 제3엄니 · 물어뜯기**, 뛰어올라 두 검을 휘두르는 **도약 쌍검**. |
| **기유** | **물의 호흡 제4형 · 들이친 파도**로 공격합니다. 강적의 반격은 제11형 **잔잔한 물결**로 막습니다. |

## 바탕화면에 데려오기

아래 [릴리스의 Assets](https://github.com/baesaa0304/demon-slayer-pets/releases/tag/v1.0.0)에서 **DemonSlayerPets.exe**를 내려받아 실행하세요. 다른 캐릭터를 만나려면 작업 표시줄 오른쪽 알림 영역의 **Demon Slayer Pets** 아이콘을 우클릭하세요.

펫을 톡 누르면 기술을 쓰고, 위로 끌었다 놓으면 공중에서 몸을 틀며 착지해요. 한동안 지켜보면 스스로 기술을 쓰기도 해요.

## 혈귀가 찾아오면

오늘의 전투 기술을 골라 혈귀를 불러보세요. 손 혈귀는 한 번의 공격으로 쓰러지지 않고, 기유는 반격이 들어오는 순간 **잔잔한 물결**로 막아내요. **혈귀 전체 소환**을 고르면 불러둔 펫들이 각자 혈귀를 맡아 싸워요.

조용히 함께 두고 싶은 날엔 알림 영역에서 자동 기술 재생과 혈귀 자동 등장을 끌 수 있어요.
